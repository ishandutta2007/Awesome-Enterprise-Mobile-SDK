# Awesome-Enterprise-Mobile-SDK

## Top Enterprise Mobile SDK Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Cross-Platform Development, Native Integration & Mobile Infrastructure*  

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Enterprise Mobile SDKs**. These tools enable organizations to build, deploy, and maintain mobile applications that integrate with enterprise systems—from CRM and cloud services to real-time communication and offline-first data sync.



**Examples** include Salesforce Mobile SDK, Firebase, AWS Amplify, Ionic Enterprise, Cordova Enterprise, React Native, Flutter, Twilio Voice SDK, Sendbird Mobile SDK, and Couchbase Mobile (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom mobile backends, and open cross-platform frameworks—ideal for mobile developers, enterprise architects, and organizations seeking transparent, vendor-independent mobile infrastructure.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Salesforce Mobile SDK](https://developer.salesforce.com/docs/platform/mobile-sdk/overview)**  

  Libraries and tools for building native and hybrid mobile apps on iOS and Android that integrate with Salesforce. Supports Swift, Objective-C, Java, Kotlin, and React Native with built-in authentication, data synchronization, and offline capabilities. Also offers Agentforce Mobile SDK for embedding AI agents into mobile apps .



- **[Firebase](https://firebase.google.com/)**  

  Google's mobile development platform with 20+ services. Core services include Authentication, Cloud Firestore, Realtime Database, Cloud Messaging (FCM), Remote Config, Crashlytics, and Analytics. SDKs for Android, iOS, Web, Flutter, Unity, and C++ .



- **[AWS Amplify](https://aws.amazon.com/amplify/)**  

  Declarative JavaScript library for frontend and mobile developers building cloud-enabled applications. Works with React Native and any JavaScript-based frontend. Features Authentication (Cognito), DataStore (AppSync offline sync), Storage (S3), API (REST/GraphQL), Push Notifications (Pinpoint), and Predictions (ML services). AWS Amplify v6 is current; v4 and below deprecated .



- **[Ionic Enterprise](https://ionic.io/)**  

  Cross-platform UI toolkit for building native-quality iOS, Android, and Progressive Web Apps with HTML, CSS, and JavaScript. Based on Web Components with support for Angular, React, and Vue. Enterprise offering adds support, SLAs, and premium features .



- **[Cordova Enterprise](https://cordova.apache.org/)**  

  Mobile application development framework using HTML, CSS, and JavaScript. Cordova Android is an Apache project. Enterprise distributions provide commercial support, security patches, and additional plugins .



- **[React Native](https://reactnative.dev/)**  

  Facebook's framework for building native mobile apps using React. Supports iOS and Android with a single JavaScript/TypeScript codebase. New Architecture (Fabric, TurboModules) is the current standard. React Native 0.77+ supports Swift natively for iOS .



- **[Flutter](https://flutter.dev/)**  

  Google's UI toolkit for building natively compiled applications for mobile, web, and desktop from a single Dart codebase. Known for high-performance rendering and expressive UI.



- **[Twilio Voice SDK](https://www.twilio.com/docs/voice/sdks)**  

  Programmable Voice SDK for adding VoIP calling to mobile apps. React Native SDK supports Expo framework and New Architecture. Native iOS and Android SDKs available. Features PreflightTest for call quality evaluation and custom ICE server support .



- **[Sendbird Mobile SDK](https://sendbird.com/)**  

  Chat, Calls, and Video SDKs for mobile apps. Chat SDK for Android supports real-time messaging with channel management, message history, and push notifications via FCM. Calls SDK provides voice/video calling with call history and mute/camera controls. Used by Reddit, Hinge, PubG, and Paytm .



- **[Couchbase Mobile](https://www.couchbase.com/products/mobile/)**  

  Embedded NoSQL database (Couchbase Lite) with Sync Gateway for offline-first mobile apps. Supports cloud sync and peer-to-peer sync (Enterprise Edition). Encrypted sync, delta sync, and multi-peer mesh networking available. Community Edition lacks P2P sync .



## Open-Source GitHub Projects



- **[Ionic Framework](https://github.com/ionic-team/ionic-framework)**  

  Powerful cross-platform UI toolkit (MIT) for building native-quality iOS, Android, and Progressive Web Apps with HTML, CSS, and JavaScript. Based on Web Components with Angular, React, and Vue integrations. 52,600+ GitHub stars, 13,323+ forks .



- **[React Native](https://github.com/facebook/react-native)**  

  Facebook's framework (MIT) for building native mobile apps with React. 120,000+ GitHub stars. Supports New Architecture with Fabric and TurboModules. Hermes JavaScript engine for optimized performance. React 19.1.1 support in recent releases .



- **[Apache Cordova Android](https://github.com/apache/cordova-android)**  

  Android application library (Apache-2.0) for building Cordova-based projects. Web technology core (HTML, CSS, JavaScript) compiled to native Android apps. Part of The Apache Software Foundation .



- **[Firebase Android SDK](https://github.com/firebase/firebase-android-sdk)**  

  Firebase Android SDK source (Apache-2.0). Collection of libraries published as Maven artifacts. Features annotations (@Keep, @KeepForSdk, @PublicApi) for tooling. Integration testing on emulator and Firebase Test Lab .



- **[AWS Amplify JS](https://github.com/aws-amplify/amplify-js)**  

  Declarative JavaScript library (Apache-2.0) for cloud-enabled apps. v5 and v6 actively supported; v4 deprecated April 2026. Works with React Native and any JavaScript frontend. Open and pluggable for custom backends .



- **[Twilio Voice React Native](https://github.com/twilio/twilio-voice-react-native)**  

  React Native wrapper (MIT) for Twilio Voice SDKs. Version 2.0.0-preview supports Expo framework. New Architecture support in 1.6.0+. Custom ICE servers and ICE transport policy for outgoing calls. Updated native iOS (6.13.6) and Android (6.10.3) SDK dependencies .



- **[Sendbird Chat SDK Android](https://github.com/sendbird/sendbird-chat-sdk-android)**  

  Real-time chat SDK for Android (Apache-2.0). Features channel management, message sending, and channel event delegates. Requires Android 5.0+ (API 21), Java 8+, FCM 19.0.1+. TLS 1.3 enabled by default (requires Conscrypt). Published via Maven at repo.sendbird.com .



- **[Sendbird Calls Android](https://github.com/sendbird/sendbird-calls-android)**  

  Voice and video call SDK for Android (Apache-2.0). Handles FCM push for background incoming calls. Features mute/unmute, video controls, camera switching, and call history queries. SendBirdVideoView auto-mirrors front camera .



- **[Couchbase Lite Android KTX](https://github.com/couchbase-examples/android-kotlin-cbl-learning-path)**  

  Couchbase Lite SDK for Kotlin/Android (Apache-2.0). Key-value engine, QueryBuilder, and SQL++ querying. Cloud sync via Sync Gateway or Capella App Services. Peer-to-peer sync (MultipeerReplicator) requires Enterprise Edition. Reactive data flow via StateFlows .



- **[Salesforce Mobile SDK Templates](https://github.com/forcedotcom/SalesforceMobileSDK-Templates)**  

  Official Salesforce templates (BSD-3-Clause) for iOS and Android mobile app development. Provides scaffolding for authentication, MobileSync, SmartStore offline storage, and REST integration. Skills-based setup via `npx skills add` .



- **[Agentforce Mobile SDK iOS](https://github.com/salesforce/AgentforceMobileSDK-iOS)**  

  Salesforce's AI agent SDK for iOS (BSD-3-Clause). Requires iOS 17+, Xcode 16+, Swift 5+. Features AgentforceSDK (core chat/agent APIs) and AgentforceVoice (optional voice experience via LiveKit). Installation via SPM or CocoaPods .



### Additional Strong Open-Source Options



- **[Flutter](https://github.com/flutter/flutter)** — Google's UI toolkit (BSD-3-Clause) for natively compiled cross-platform apps.

- **[Expo](https://github.com/expo/expo)** — Framework and platform (MIT) for universal React Native apps with managed workflow.

- **[Capacitor](https://github.com/ionic-team/capacitor)** — Cross-platform native runtime (MIT) for web apps, successor to Cordova.

- **[NativeScript](https://github.com/NativeScript/NativeScript)** — Framework (Apache-2.0) for building native mobile apps with JavaScript/TypeScript.

- **[Realm](https://github.com/realm/realm-kotlin)** — Mobile database (Apache-2.0) with offline-first sync capabilities.

- **[ObjectBox](https://github.com/objectbox/objectbox-java)** — High-performance mobile database (Apache-2.0) for Android, iOS, and Flutter.

- **[SQLDelight](https://github.com/sqldelight/sqldelight)** — Kotlin Multiplatform database library (Apache-2.0) generating typesafe Kotlin from SQL.

- Community **n8n** workflows for mobile backend automation and push notification routing.



**Frameworks for building custom systems**: Combine **React Native** or **Flutter** as the cross-platform UI layer with **Firebase** or **AWS Amplify** for cloud services, **Couchbase Lite** or **Realm** for offline-first data persistence, **Twilio Voice** or **Sendbird** for real-time communication, and **Salesforce Mobile SDK** for CRM integration—creating a fully self-hosted, enterprise-grade mobile platform.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Mobile SDKs handling user data must comply with data protection regulations (GDPR, CCPA, etc.) and platform store policies (Apple App Store, Google Play).

- Self-hosted open-source solutions require proper security hardening, dependency management, and ongoing maintenance. Mobile SDK version deprecations (e.g., AWS Amplify v4 ending support April 2026) require migration planning.
